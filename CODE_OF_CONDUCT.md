# Code of conduct

This project follows the spirit of the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our standards

- Be respectful and constructive, in English, Chinese or any other language.
- Assume good faith, and critique code and ideas, not people.
- Welcome newcomers and help them get their first contribution merged.
- Harassment, personal attacks, discriminatory language and publishing other people's private information are not acceptable.

## Scope

This applies to issues, pull requests, discussions and any other space connected with the project.

## Enforcement

Report unacceptable behaviour privately to the maintainer through the contact options on [the maintainer's GitHub profile](https://github.com/Akxan). Reports are handled confidentially. The maintainer may edit or remove comments, close threads and block participants who break these standards.

> 中文：请友善、建设性地交流，对事不对人；骚扰、人身攻击、歧视性言论和公开他人隐私都不被接受。
